# QzoneCleaner

QQ空间净化脚本，提供毛玻璃效果、二次元背景替换等功能。

## 功能特性

- 🎨 毛玻璃效果导航栏
- 🖼️ 二次元壁纸自动替换背景
- 🚫 隐藏广告和推广内容
- 🎭 隐藏黄钻信息
- ✨ 圆角卡片设计

## 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装脚本](https://github.com/user/QzoneCleaner/raw/main/QzoneCleaner.user.js)
3. 刷新QQ空间页面即可生效
